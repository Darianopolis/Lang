# Lang

Experimental general purpose language project

## Notable language aspects

- Everything is first class
  - Types and functions are first-class values
  - All type expressions are normal compile time expressions
- Sane operators
  - Partial independent left/right operator precedence, open for extensibility in the future
  - Precedence/associativity only defined for clear and well understand cases
  - Postfix dereference operator
